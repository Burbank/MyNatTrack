      ARINC 424 quick lookup

      Type these into the route field. Letter last = longitude < 100°; letter 3rd = longitude ≥ 100°. Letter key: N = N/W · E = N/E · S = S/E · W = S/W.

      Entry Meaning
      5215N 52°N 015°W (letter last → lon < 100°)
      5050N 50°N 050°W
      50N50 50°N 150°W (letter 3rd → lon ≥ 100°)
      4020S 40°S 020°E
      H5250 52°30′N 050°W (NAT half-degree)
      N5050 50°30′N 050°W (classic N-prefix; prefer H when possible)
      N5000.0W05000.0 Full FMS lat/lon
      Paste route example: SOMAX 5020N 4930N 4740N 43N050W SOORY

      MNPS Route Verification

      8.3.2.11.3 · Reference only — follow current company OM / AIP procedures

      A · Before entering MNPS airspace
      1
      Dual listening & recording
      • Both PF & PM listen and record every ATC clearance
      • Agree recording is correct
      • Independent clearance copy, data entry, crosschecks
      • Also for enroute changes · Cannot be delegated
      2
      PM — OFP note & route comparison
      • Enter clearance as Note in OFP
      • ACARS → reference i.a.w. OM-A 8.1.10.2
      • Check cleared route vs flight plan
      Cleared ≠ FPL?
      (i) Revise WPT name
      (ii) Crossload OFP and Notes
      Same
      Continue
      3
      PF — Clearance vs OFP + FMS
      • Check clearance vs (NAVLOG) OFP
      • Enter / verify route in FMS
      • (i) Full Lat/Long (expand coded e.g. 4550N)
      • (ii) Sequence & number · (iii) Distances
      4
      PM — FMS → OFP
      • Verify from FMS to OFP
      • Waypoint sequence & number
      5
      Flight Note
      • Report in FLIGHT NOTE that check in (1) was performed
      B · In MNPS airspace
      WPT
      Passing waypoints
      • (i) Just prior: present position vs OFP (each FMS)
      • (ii) Next two WPTs in each FMS vs OFP
      • (iii) Distance, correct turn, new heading/track
      • (iv) Before position report: verify coords; read “next” + “next+1” from steering CDU if feasible
      Reclearance?
      Voice or ACARS
      Yes → return to (a) steps 1–4
      Full independent verification
      No
      Continue MNPS

      Notes

      • All steps in (a) must be performed independently and in sequence.
      • Coded waypoints (e.g. 4550N) must be expanded to full Latitude/Longitude.
      • Dual verification (PF ↔ PM) is mandatory and cannot be delegated.
      • On any reclearance (voice or ACARS) re-apply full pre-entry (a)(1)–(a)(4).
