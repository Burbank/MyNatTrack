    Waypoint accuracy last verified on 2026-07-26
    
          
    
            Educational and Simulator use only. Not certified for navigation.
    
            WGS-84 Vincenty tracks & distances; magnetic variation is an approximate offline model.
          
    
          
    
            Ownship (Fly): coarse location only — Precise Location is not required.
            When stationary, cockpit lat/lon appears beside the UTC clock (mini and full screen);
            tap to copy an FMS paste string (e.g. N2546.3W08011.4) and centre the chart. Hidden while moving.
            To stop Safari asking each visit: iPad Settings → Apps → Safari → Location → Allow
            (or Settings → Safari → Location). Sites cannot store a lasting “permission cookie” for GPS;
            that choice lives in Safari/iOS settings.
          
    
          
    
            Educational jam / spoof cues (not certified):
            (1) Position — while stationary, a twin chip shows the nearest airport ARP (vertical IATA when known, else ICAO)
            with ARP coords and NM. If you are within ~25 NM of that field and GPS is more than 4 NM from the ARP,
            present position and the ARP chip turn amber. Mid-ocean “nearest airport hundreds of NM away” does not amber.
            (2) Time — whenever a GPS fix is available (including while moving), the app compares the fix timestamp
            with the iPad system clock. If they differ by more than 10 seconds, the UTC letters on the clock
            turn amber (digits stay normal). Clear when GPS is lost. Browser location time is OS fix time, not certified GNSS time.
          
    
          
    
            Full-screen with no route: 747-8 airports appear on the chart; tap or type two for a great-circle plan (NM + rough time with westerlies).
            Those ICAOs are also in the route database for normal entry. Cleared on exit full screen.
          
    
          
    
            Teach: when editing a single waypoint (or typing one name), use Teach (left of Update/Add) to enter or correct chart coordinates.
            Your manual fix is kept on this device and is never overwritten by online lookups. Use Teach again anytime to revise it.
          
    
          
    
            Coordinate sources (official over OpenNav):
            Transport Canada AIM NAT Table 1.1 for Gander 050°W OEPs;
            AirNav Ireland AIP ENR 4.4 for SOMAX/DOGAL/MALOT/LIMRI;
            FAA NFDC Fixes/Waypoints for US / many oceanic fixes.
            Online lookup uses FAA only (OpenNav is not used). Eurocontrol EAD requires registration, so some European fixes may still be approximate until Teach/AIP.
          
    
          
    
            Fullscreen weather: Storm systems and SIGMETs (NHC + all text SIGMETs including convective/VA, cached 12h; valid only; volcano icons at published PSN)
            and Live Thunderstorms (RainViewer radar intensity only — regional zoom, land/coastal coverage).
            Tap a SIGMET/volcano for the raw text. Educational — not for dispatch.
          
    
          
    
            
    
              iCloud Drive backup — Safari cannot write directly into iCloud, but Files can.
              Export your learned / Teach database, then in the share sheet choose
              Save to Files → iCloud Drive (e.g. a MyNatTrack folder).
              On another iPad or MacBook, open this app → Import from that same file.
              Keep one file and overwrite it when you Teach new fixes so both devices stay aligned.

      ARINC 424 quick lookup
      
          
      
            Type these into the route field. Letter last = longitude < 100°; letter 3rd = longitude ≥ 100°.
            Letter key: N = N/W · E = N/E · S = S/E · W = S/W.
          
      
          
      
            
              
      
                Entry
                Meaning
              
      
                  
            
              
      
                5215N
                52°N 015°W (letter last → lon < 100°)
              
      
              
      
                5050N
                50°N 050°W
              
      
              
      
                50N50
                50°N 150°W (letter 3rd → lon ≥ 100°)
              
      
              
      
                4020S
                40°S 020°E
              
      
              
      
                H5250
                52°30′N 050°W (NAT half-degree)
